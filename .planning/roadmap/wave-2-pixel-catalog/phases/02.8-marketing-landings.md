# Phase 02.8 — Marketing-лендинги (Astro) на профики.online (seed-spec)

> Seed-spec per [DoR](../../DEFINITION-OF-READY.md). Источник метрики «регистрации из публичного трафика». Домен решён: **профики.online** (D-12) — корень = лендинги, `app.` = приложение.

- **Status:** ⏳ Pending · **Queue:** после 02.7 — непосредственно перед открытием трафика

**Goal:** публичный маркетинг-сайт на профики.online live: главная (horizontal-оффер) + 2 vertical-страницы (Маркетинг-агентство, Telegram-крейтор) + прайсинг + waitlist-страницы «Скоро», с CTA → регистрация на app.профики.online; SEO-база готова.

**Scope (in):** Astro 5 суб-проект в репо (`marketing/`); дизайн наследует DS v0.3 (02.2), строго professional (без пиксель-скина — оut-of-scope 02.6); страницы: главная, 2 вертикали, прайсинг (тарифы из `billing.plans`; отображение «скоро» до live 01.3b), waitlist ИП-Бух/СМБ-Sales (шов 02.5), privacy/terms (⚠️ **юр-текстов НЕ существует** — `TBD_PRIVACY_POLICY_URL` / `TBD_TOS_URL` / `TBD_PDN_CONSENT_TEXT_URL` в статусе ⏳; поставляются через **RW-13**, см. Gating); SEO: мета/OG/sitemap/robots, семантическая разметка, скорость (Lighthouse); деплой в текущий Caddy/VPS-контур (корень домена) + `app.` маршрутизация SPA; копирайтинг: агенты драфтят на базе review-packages вертикалей + позиционирования, **founder утверждает тексты и прайсинг ДО публикации** (внешняя публикация = обязательный ack).

**Out-of-scope:** платный трафик/рекламные кампании (founder-работа вне волны); блог/контент-маркетинг (W3); vc.ru/Хабр публикации (founder-канал, зависимость метрики, не фазы); англоязычная версия.

**ADR-refs:** ADR-001, ADR-017, ADR-042, ADR-031.

**Gating/Runway:** домен профики.online уже у founder (D-12); DNS-записи корня → founder-действие при деплое (5 мин); утверждение текстов/прайсинга — founder-touchpoint. Tripwire-прогноз: новый суб-проект + infra (Caddy) → ack-needed (infra-пути).

**🔴 БЛОКЕР — RW-13, юрпакет публичного запуска (D-36).** Эта фаза открывает **публичное предложение**: до неё бета закрытая, дружеская, по личным приглашениям (02.0), и юр-обязательства ограничены. С публикацией лендингов + waitlist + регистрации из органики появляется неопределённый круг субъектов ПДн. Требуется ДО публикации: Политика конфиденциальности, ТоС, текст согласия на ПДн, **уведомление РКН об операторе (OQ-04)**, юрист на retainer (**OQ-03 — OVERDUE с Wave 1**). Без RW-13 фаза паркуется (ADR-040 D7) — dev-часть (Astro/SEO/деплой) может быть построена, но **публикация не выполняется**. Путь длинный (поиск юриста + процедура РКН) → стартовать параллельно RW-04 на неделе 1–2, а не по приходу очереди.

**Evidence-гейты:** Lighthouse ≥90 perf/SEO/a11y на всех страницах; линк-чек; axe; e2e CTA → живая регистрация на staging. Live-golden: **N/A ($0)**.

**AC-направления:** все страницы отдаются с корня домена с валидным TLS; CTA-путь до регистрации ≤2 клика; прайсинг соответствует `billing.plans`; waitlist пишет в тот же стор, что 02.5; founder-ack на публикацию зафиксирован; sitemap/robots корректны.
