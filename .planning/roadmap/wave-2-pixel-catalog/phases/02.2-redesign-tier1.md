# Phase 02.2 — Tier-1 редизайн: UX-research → IA/навигация → дизайн-система v0.3 (seed-spec)

> Seed-spec per [DoR](../../DEFINITION-OF-READY.md). Крупнейшая фаза волны; заложена по решению founder (grill 2026-07-11, D-24): «фундаментальное исследование трендов UI/UX → пересборка с фокусом на удобство и эффективную навигацию; хочу tier-1 дизайн, готов уделить время». Направление фиксируется новым [ADR-042](../../../decisions/ADR-042-wave2-tier1-redesign.md).

- **Status:** ⏳ Pending · **Queue:** сразу после 02.1-retro — всё последующее (approval-UI, onboarding, Pixel, лендинги) строится на новых токенах

**Goal:** приложение пересобрано на дизайн-системе v0.3 (палитра/типографика/спейсинг/тени + пересмотренные IA/навигация/лейауты) уровня tier-1 SaaS; все существующие фичи работают на новом дизайне; founder утвердил результат.

**Scope (in):**
1. **Research-этап** (research-first, по образцу вертикалей): анализ трендов UI/UX веб-сервисов 2025–2026 (tier-1 SaaS референсы: навигационные паттерны, density, dark/light, motion), синтез в дизайн-бриф + фидбек друзей волны-1 из 02.0 как вход;
2. **IA/навигация:** пересмотр информационной архитектуры (sidebar/страницы ячеек/задачи/артефакты/память/dashboard), карта переходов, UI-SPEC контракт;
3. **Дизайн-система v0.3:** значения токенов + полная var-индирекция (radius/font/shadow — субстрат из 02.1-retro), обе темы (dark/light), WCAG AA пересчёт всей палитры;
4. **Пересборка экранов** под новые токены/лейауты + обновление unit/e2e/axe-тестов;
5. **Founder-touchpoints (несколько, время committed):** (a) дизайн-бриф по итогам research; (b) IA-предложение; (c) live bake-off 2–3 направлений на реальных экранах (процесс 00.8 повторяем); (d) финальное утверждение.

**Out-of-scope:** pixel-скин (02.6 — отдельная ось `data-skin` поверх v0.3); лендинги (02.8 — наследуют DS); ребрендинг имени/лого-редизайн вне палитры (бренд «Профики» зафиксирован); мобильное приложение.

**ADR-refs:** ADR-042 (new, направление — Proposed до bake-off), ADR-031 (v0.2 — superseded частично), ADR-016, ADR-028 (P-DESIGN-1 token-change protocol).

**Gating/Runway:** founder-время на 4 touchpoints (committed, интервью 2026-07-11). Dev-зависимость: var-индирекция из 02.1-retro. Tripwire-прогноз: чистый frontend → вероятен exit 0 auto-merge по коду, но продуктовые чекпойнты (a)–(d) — обязательные founder-стопы фазы.

**Evidence-гейты:** lint/tsc/vitest/coverage ≥ текущих порогов; axe 0 serious/critical на всех роутах × обе темы; visual-diff скриншот-пакет к bake-off; UI-SPEC контракт в `ui/`. Live-golden: **N/A ($0)** — LLM не вызывается (research — web+dev-team бюджет).

**AC-направления:** IA-карта утверждена founder; DS v0.3 материализована в tokens+`themes.css` с var-индирекцией 100% (grep-гейт: ни одного литерального radius/font/shadow в утилитах); все экраны пересобраны без функциональных регрессий (существующие тесты зелёные после адаптации); axe AA обе темы; bake-off проведён, выбор зафиксирован в ADR-042 (Proposed→Accepted); TTFV не деградировал (замер 02.0).
