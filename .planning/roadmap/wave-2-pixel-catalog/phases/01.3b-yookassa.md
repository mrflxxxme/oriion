# Phase 01.3b — ЮKassa: рекуррентная подписка + credit-паки (seed-spec, carry-over из W1)

> Seed-spec per [DoR](../../DEFINITION-OF-READY.md). Перенос из Wave 1 (parked, RW-04). Платёжная модель решена grill 2026-07-11 (D-11): **рекуррентная подписка с автопродлением + разовые credit-паки**. Billing-core (планы/Trial/caps/ledger) готов с 01.3.

- **Status:** ⏳ **Parked-until-RW-04** · **Queue:** вливается в очередь сразу по разблокировке (ожидаемо середина волны); **founder стартует RW-04 (OQ-02 юр.форма + заявка ЮKassa, 5–10 раб. дней) НА НЕДЕЛЕ 1 волны** (D-02)

**Goal:** пользователь оплачивает подписку (Solo/Команда) картой через ЮKassa с автопродлением и докупает credit-паки; кредиты зачисляются в существующий ledger; чеки уходят через ЮKassa (54-ФЗ); тест-shop → live-flip по готовности.

**Scope (in):** интеграция ЮKassa API (создание платежа, сохранение payment-method для рекуррента, автосписание по циклу подписки); webhook-обработчик (идемпотентный, подпись проверяется) → активация/продление `billing.subscriptions` + начисление кредитов в ledger; credit-паки (каталог + разовый платёж → грант); отмена подписки/грейс-период; экраны оплаты/управления подпиской (DS v0.3); dunning-минимум (ретрай неудачного автосписания + email); тест-shop сценарии полного цикла; live-flip как отдельный финальный шаг с founder-ack.

**Out-of-scope:** rollover/overage-политики (deferred с 01.3); Telegram Stars (W3+, ADR-030); enforcement квот сторэджа (02.10 — отдельно); возвраты сверх минимального ручного процесса; юр-тексты оферты (founder+юрист параллельно, гейтит только live-flip).

**ADR-refs:** ADR-008, ADR-040 (D7 runway-парковка).

**Gating/Runway:** **RW-04** (OQ-02 ООО-vs-ИП + счёт + тест-shop `shopId`/секрет) — жёсткий гейт старта; live-flip дополнительно гейтится офертой. Tripwire-прогноз: `db_migrations` (payment-таблицы) + `public_api_contracts` + `secrets_keys_crypto` (ЮKassa-секрет в KMS/env) → ack-needed.

**Evidence-гейты:** **adversarial-аудит обязателен** (деньги: идемпотентность webhook'ов, replay-атаки, подпись, двойное зачисление); integration real-PG; тест-shop e2e полного цикла (подписка → автопродление симуляция → пак → отмена). Live-golden: **N/A LLM ($0)**; тест-shop транзакции бесплатны.

**AC-направления:** оплата тест-shop активирует подписку и начисляет кредиты (сумма = каталог плана); повторный webhook не дублирует грант; автосписание продлевает подписку; отмена останавливает списания с корректным доступом до конца периода; billing-инвариант ledger сохранён; чек формируется на стороне ЮKassa; конверсионная воронка «увидел прайсинг → оплатил» замеряется (вход в gate-метрики).
