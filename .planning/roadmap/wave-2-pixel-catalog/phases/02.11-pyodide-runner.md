# Phase 02.11 — Pyodide-runner для Analyst (seed-spec)

> Seed-spec per [DoR](../../DEFINITION-OF-READY.md). Закрывает Analyst capability-gap из Wave 0. UX-модель решена grill 2026-07-11 (D-14): **код-артефакт + явная кнопка «Run»** (не авто-исполнение).

- **Status:** ⏳ Pending · **Queue:** замыкающая фаза волны

**Goal:** Analyst-роль производит python-код как артефакт; пользователь по кнопке «Run» исполняет его в своём браузере (Pyodide WASM, изолированный web worker); результат (stdout/таблица/график) прикрепляется новой версией артефакта.

**Scope (in):** worker-инфраструктура (`src/workers/`, module-worker Vite; Pyodide **pinned version** per R-27, lazy-load с самохостом ассетов — CSP/COOP-COEP решение в Caddy при необходимости); артефакт-тип «код+результат» (envelope 01.5 переиспользуется: код = версия, результат = следующая версия с `text_export`); Run-кнопка с явным предупреждением + таймаут/отмена исполнения; захват stdout/matplotlib-фигур/датафреймов в отображаемый результат; «desktop recommended» UX для тяжёлых вычислений (R-28); prompt-обновление Analyst-роли (выдавать исполнимый код с контрактом вывода) + golden-задачи на код-путь.

**Out-of-scope:** интерактивный ноутбук (ячейки/редактирование — W3-кандидат, D-14); server-side исполнение (gVisor/Firecracker — W3+ per ADR-006); установка произвольных pip-пакетов (белый список Pyodide-пакетов); доступ кода к API приложения (worker без сети к нашему бэку — изоляция).

**ADR-refs:** ADR-020, ADR-006, ADR-012/038 (артефакт-версии), ADR-010 (Analyst prompt bump).

**Gating/Runway:** founder-зависимостей нет. Tripwire-прогноз: frontend + prompt-файл под `contracts/` (`public_api_contracts` additive) → лёгкий ack.

**Evidence-гейты:** unit на worker-протокол (мок Pyodide) + e2e @live: Analyst-задача → код-артефакт → Run → результат-версия; security-линза adversarial (код не достаёт токены/localStorage/наш API из worker'а); perf-smoke загрузки Pyodide. Live-golden бюджет: **~$0.5** (генерация код-артефактов живой моделью).

**AC-направления:** код исполняется ТОЛЬКО по явному Run; worker изолирован (нет доступа к auth-токенам/DOM/нашему API — тест); результат версионируется и citeable через `artifact://`; таймаут прерывает зависший код без падения вкладки; версия Pyodide pinned и самохостится; Analyst golden-задача на код-путь зелёная.
