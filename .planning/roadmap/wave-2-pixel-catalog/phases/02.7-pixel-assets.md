# Phase 02.7 — Pixel-ассеты: API-генерация 24 архетипов + курация + пиксель-тур (seed-spec)

> Seed-spec per [DoR](../../DEFINITION-OF-READY.md). Решения grill 2026-07-11: D-09 (API-генерация вместо ComfyUI/GPU per ADR-021-amendment), D-10 (гейт волны = скин live + AI-бейзлайн; hand-drawn герои — asset-апдейт вне гейта), D-23 (пиксель-тур шагом онбординга — в этой фазе, когда спрайты существуют).

- **Status:** ⏳ Pending · **Queue:** после 02.6

**Goal:** 24 AI-generated архетипа (profile+idle+working) сгенерированы, откурированы founder'ом, версионированы в Object Storage и живут в скине 02.6 вместо placeholder'ов; онбординг получает опциональный пиксель-тур; hand-drawn герои (SMM-Анастасия, Крейтор-Денис — RW-10) вливаются позже отдельным asset-апдейтом.

**Scope (in):** генерация батчей через image-gen API (провайдер выбирается на discuss по качеству пиксель-арта + лицензии; ключ — RW-11) по мастер-промпт-шаблону ADR-021 (32×32, front-facing, retro 16-bit, transparent); авто-postprocess пайплайн (downscale/palette-quantize до пиксель-сетки, sprite-sheet сборка 4-frame idle); **страница-контактный-лист для founder-курации** (батч-review: выбрать финалиста на архетип, перегенерировать слабые); деплой в Object Storage `/assets/agents/<archetype_id>/<state>.png?v=` (immutable cache, version из `agents.agent_archetypes.version` per ADR-021/024); лицензионный чек выбранного API-провайдера (training data / ownership); пиксель-тур в onboarding-wizard (опциональный шаг «познакомьтесь с командой» с превью и предложением включить скин — D-23); приёмный шов для hand-drawn героев (64×64, 6 состояний — тот же пайплайн деплоя).

**Out-of-scope:** сами hand-drawn герои (внешний художник, RW-10 — founder-трек; вливаются апдейтом без фазы); Telegram-стикеры/маркетинг-материалы из героев (пост-волна); анимации сверх idle/working для архетипов (W3).

**ADR-refs:** ADR-021 (amended: API-ген), ADR-004 (amended), ADR-024 (`agent_archetypes.version`).

**Gating/Runway:** **RW-11** — API-ключ image-gen сервиса (~$20–50, founder кладёт в `.env`); **RW-10** — наём художника (не гейтит фазу и волну — D-10). Founder-курация — обязательный touchpoint (≈1–2 часа батч-review). Tripwire-прогноз: frontend + assets + возможно `db_migrations`-соседство (version bump-логика) → вероятен лёгкий ack.

**Evidence-гейты:** пайплайн-тесты (postprocess детерминирован: фикс-инпут → фикс-спрайтшит); лицензионный чек-отчёт в каноне; visual-QA чек-лист курации подписан founder. Live-бюджет: **~$20–50 image-gen (RW-11)**, LLM N/A.

**AC-направления:** 24/24 архетипа откурированы и задеплоены с versioning (immutable URL); скин 02.6 переключён с placeholder на финальные без код-изменений (только version bump); тур в онбординге опционален и пропускаем; лицензия провайдера зафиксирована; герой-шов принимает 64×64×6 без доработок (проверено на тест-ассете).
