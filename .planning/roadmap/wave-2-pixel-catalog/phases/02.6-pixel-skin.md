# Phase 02.6 — Pixel Department: полный скин-режим + офис (seed-spec)

> Seed-spec per [DoR](../../DEFINITION-OF-READY.md). Пиксельная инфраструктура БЕЗ финальных ассетов (ассеты — 02.7): полный opt-in скин-режим UI поверх DS v0.3 + офис-витрина с live-состояниями. Решения grill 2026-07-11: D-20 (полный скин), D-21 (live-состояния по SSE), D-22 (офис = секция cell + виджет Dashboard).

- **Status:** ⏳ Pending · **Queue:** после 02.5

**Goal:** пользователь включает «Пиксельный офис» (off by default) — приложение переключается в пиксель-режим (радиусы→0, пиксель-акценты типографики, ретро-детали) с офисом-витриной команды, где спрайты агентов живут по состояниям реальных задач; на placeholder-ассетах, готово к подмене финальными из 02.7.

**Scope (in):** ось `[data-skin="pixel"]` рядом с `data-theme` (отдельное поле theme-store, применение по образцу `applyTheme`; НЕ расширение union) поверх var-индирекции DS v0.3 — радиусы/шрифты/тени/акценты переключаются скином; тумблер в настройках (persist per-user) + ненавязчивый hint после первой выполненной задачи; `<AgentSprite>` (Canvas 2D, sprite-sheet, retina 2×, pixelBob) с fallback на обычный аватар; офис-секция на странице ячейки (сетка карточек команды) + мини-виджет «команда сейчас» на Dashboard; **live-состояния**: маппинг SSE-событий прогресса → `idle/working/success` (у героев + `thinking/error`); замена стандартных аватаров агентов на pixel-`profile` при включённом скине; placeholder-ассеты (временные спрайты) на весь каталог архетипов.

**Out-of-scope:** генерация/интеграция финальных ассетов (02.7); полная 2D-сцена офиса с рассадкой (W3 per ADR-004); пиксель-скин лендингов (02.8 — professional only); скин в onboarding до включения (первое впечатление professional — D-23 тур идёт после 02.7).

**ADR-refs:** ADR-004 (amended 2026-07-11), ADR-021 (amended), ADR-031, ADR-042.

**Gating/Runway:** зависит от 02.2 (var-индирекция + DS v0.3). Founder-зависимостей нет. Tripwire-прогноз: чистый frontend → вероятен exit 0 auto-merge.

**Evidence-гейты:** axe AA в пиксель-скине × обе темы (контраст пиксель-палитры — блокирующий); vitest на skin-store/маппинг состояний; e2e: задача при включённом скине → спрайты переключают состояния; perf-smoke (Canvas не роняет FPS списков). Live-golden: **N/A ($0)**.

**AC-направления:** скин off by default и включается/выключается без перезагрузки; при выключенном скине UI бит-в-бит соответствует DS v0.3 (visual-diff); live-состояния отражают SSE в ≤1s; все точки аватаров переключены; hint показывается однократно; axe AA в скине.
