## Goal

Новый bounded context `artifacts`: персистентное хранилище work products —
**Yjs-документы** (CRDT, bytea + pycrdt, REST-only персистентность) + **S3-ассеты**
(presigned upload → MinIO/Yandex Object Storage) + **citeable `artifact://` URLs**
(стабильные, включая исторические версии). Envelope-модель per ADR-038; existing
`tasks.task_artifacts` refs (`s3_key`, `yjs_document_id`) получают queryable targets
без изменения таблицы tasks.
