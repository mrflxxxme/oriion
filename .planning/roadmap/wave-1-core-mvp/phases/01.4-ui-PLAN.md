## 1. Goal (verifiable)
Пользователь в вебе видит и контролирует память команды: панель «Что помнит команда/агент» со списком, поиском, добавлением и удалением записей **cell-memory** и **role-memory**, поверх уже-live API `/api/v1/memory/*` (01.4). ## 2. Scope
**In:** новый frontend-feature `features/memory/` + `api/memory.ts` + маршрут + навигация. Список cell + role memory; source-бейджи (`manual`/`filter_agent`/`conversation_summary`); поиск (семантический `/search`); добавление (POST); удаление с confirm-диалогом; edit = delete+add. Tokens v0.2 + axe AA (`ui/REVIEW-CHECKLIST.md`). UI-SPEC-контракт.
**Out (адресовано):** новые backend-эндпоинты / PATCH (append-only backend — [DECISIONS-LOG fork2]; если понадобится → отдельная фаза); auto-extraction settings (→ future); PARA-workspace (→ Wave 3); co-editing (→ Wave 2, RQ-20260701-001).
