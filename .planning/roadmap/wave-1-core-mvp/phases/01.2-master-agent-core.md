## Goal

Introduce the two-tier orchestration layer for **vertical** templates: a `MasterAgent`
(vertical "CEO" — domain lens + strategic planning + final domain-quality synthesis) above the
existing `Coordinator` (operational "COO"). Prove it end-to-end with **one** reference vertical
(**Marketing-agency РФ**). The horizontal `productivity-core` path stays single-layer and
byte-for-byte unchanged.

## Scope (delivered)

- `StrategicContext` typed model + optional threading on `CoordinatorDeps` (default `None`).
- `MasterAgent` orchestration (`runtime/dispatch.py`): plan call (deepseek-chat) → `StrategicContext`
  → subordinate `PlanExecutingCoordinator` (reusing the same leaf runner) → synthesis call
  (deepseek-reasoner/R1) → `MasterResponse`. **2 physical task levels** (Master-task → specialist
  child-tasks; Coordinator as `task_steps`); single budget accumulator → 50-credit cap covers the
  Master + children aggregate.
- Master prompt loader (`masters/<vertical>.md`) + the Marketing-agency Master prompt (AI baseline,
  `status: draft`) + sync-script fix (recursive `masters/` mirror).
- Marketing-agency seed (Master archetype reusing the horizontal specialists) + provisioning wiring.
- Vertical-scoped archetype resolution (`_resolve_archetype_id(..., vertical_slug=)`).
- Evaluator-gate scaffold (`verticals/agency-marketing-ru/golden-dataset/`: methodology + 2 example
  golden tasks + 5 adversarial probes).

**Out of scope (later phases):** Telegram-creator 2nd vertical + horizontal prompt-hardening (01.10);
the full 30-task golden set + the live evaluator run that promotes the prompt `draft → reviewed`
(founder domain-expertise step, ADR-026 Pattern-D); friend-loop `locked` (Wave-2 retro).
