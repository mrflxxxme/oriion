## Risks / guards

- **ПДн-утечка через логи/SSE/exception** — ключевой SECURE-инвариант: детекторы возвращают `(category, span)`, НИКОГДА сырое значение; `DlpViolation.__str__` = только категории (failure-handler эхоит `str(exc)` в SSE); audit-payload = категории+счётчики. Проверяется unit + SECURE-линзой.
- **False-positive friction** — DLP default-off (нет исходящего surface Wave-1); включается 01.9. Injection B1 недеструктивна (no-op на benign) → default-on безопасен.
- **ReDoS** в regex детекторах — линейные паттерны без catastrophic backtracking; проверяется SECURE-линзой.
- **Дестабилизация web_search тестов** — injection-sanitize no-op на benign fixtures; прогнать полный unit-suite после C8.
- **Docker down** — не блокирует: фаза без DB-таблиц/миграций, unit-only локально (ci-backend PG-сервис не нужен для этой фазы). Нет `docker_integration` evidence-гейта.
- **Budget:** реализация в основной сессии + review/audit субагенты — в пределах dev_team per-day soft cap $30.
