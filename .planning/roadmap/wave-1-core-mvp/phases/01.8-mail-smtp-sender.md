## Scope

- **Sender** `backend/src/iam/services/email_service.py`: новый класс
  `YandexSmtpEmailSender` (оба метода порта). `aiosmtplib.send` c TLS:
  `use_tls=True` → implicit TLS (SSL-on-connect, порт 465); `use_tls=False` →
  STARTTLS (порт 587), `start_tls=True` форсит апгрейд ДО AUTH (нет
  plaintext-auth по cleartext). Cert-verify на ssl-дефолте (никогда не
  отключается). MIME (`email.message.EmailMessage`): From/To/Subject +
  plaintext-тело со ссылкой-или-токеном (семантика `ConsoleEmailSender`).
- **Settings** `backend/src/_shared/config.py`: `smtp_host` (default
  `smtp.yandex.ru`), `smtp_port` (465), `smtp_use_tls` (True), `smtp_user` (""),
  `smtp_password` (SecretStr ""), `smtp_from` (""), `smtp_timeout_seconds` (30),
  `email_verify_url_base` ("") — все с безопасными дефолтами (app бутится без
  кредов). Хелперы `is_smtp_configured` + `smtp_sender_address`.
- **Selection wiring** `backend/src/iam/deps.py::get_email_sender`: dev/test →
  Console; prod **с** кредами → YandexSmtp; prod **без** кредов → NoOp fallback
  (deferred-live-send контракт, без краша).
- **Deps** `backend/pyproject.toml` + `uv.lock`: `aiosmtplib>=5.1,<6.0`
  (5.1.2, MIT, prod/stable, py.typed, 0 CVE) + RUF001 per-file-ignore для
  email_service.py (RU-контент писем интенционален).
- **Tests** `backend/tests/iam/unit/`: transport-mock (`test_email_service.py`)
  + selection (`test_email_sender_selection.py`) + `@pytest.mark.live` smoke
  scaffold.
- **OUT of scope:** реальная отправка (deferred-гейт до кредов) · HTML-письма
  (сейчас plaintext) · email-outbox таблица/миграция · шаблонизатор · bounce/
  DSN-обработка · rate-limit на отправку (уже есть на уровне auth endpoints) ·
  frontend.

## Live-send activation (cross-ref, deferred гейт — НЕ в этой фазе)

Live отправка валидируется **одной командой**, когда SMTP-креды лягут в
canonical `.env` / YC Lockbox:

```
SMTP_LIVE_TEST_TO=you@example.com SMTP_USER=no-reply@profiki.online \
SMTP_PASSWORD=<yandex-app-password> \
uv run --project backend pytest tests/iam/unit/test_email_service.py -m live
```

Env-ключи: `SMTP_HOST` (default `smtp.yandex.ru`), `SMTP_PORT` (465), `SMTP_USER`,
`SMTP_PASSWORD` (Yandex **app-password**, не пароль аккаунта), `SMTP_FROM`
(optional), `SMTP_USE_TLS` (optional, default true), `SMTP_LIVE_TEST_TO`.

Прод-активация: положить `SMTP_USER` + `SMTP_PASSWORD` (+ опц. `SMTP_FROM`,
`EMAIL_VERIFY_URL_BASE`) в Lockbox/`.env` → `get_email_sender` автоматически
переключается с NoOp на YandexSmtp (флага не требуется, детект по кредам).
