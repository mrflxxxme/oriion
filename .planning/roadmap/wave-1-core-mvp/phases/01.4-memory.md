## Goal

Give the AI team a **two-level memory** so agents recall what the cell knows and what each
agent has learned. ADR-011 Wave-1 = **cell memory** (shared knowledge base, RAG-recallable) +
**role memory** (per agent-instance preferences/style) + **conversation history** (FIFO window +
summarize-on-overflow) + a **filter-agent** (automatic extraction after a task). Storage is
pgvector with an HNSW cosine index; retrieval is a similarity-search API; writes are
manual-control («запомни») plus the filter-agent.

Scope was grilled (2026-06-23, 7 forks) against code reality (Yandex embeddings are 256-dim, not
the ADR's stale 1024; the codebase uses single-schema + RLS, not per-cell schemas; the funded
`.env` has Yandex+GigaChat+DeepSeek).

## Scope (delivered)

- **Schema** (`memory/0001_memory_core.py`, `memory/0002_conversation_history.py`): a single
  `memory` schema (grill Q3) with `memory.memory_entries` (cell), `memory.role_memory_entries`
  (+`agent_id`), `memory.conversation_history` (+`seq` IDENTITY for FIFO) — all FORCE-RLS via
  `_shared.current_cell_id()` (USING+WITH CHECK), `vector(256)` embeddings (grill Q1) + HNSW
  `vector_cosine_ops` (m=16, ef_construction=64). **Supersedes** the unused 1024-dim per-cell
  `cell_<uuid>.memory_entries` placeholder in `multitenancy/0004` (→ cleanup chip).
- **Models + repositories** (`memory/models.py`, `memory/repositories/`): `MemoryEntry`,
  `RoleMemoryEntry`, `ConversationMessage` (single-source `MEMORY_EMBEDDING_DIM=256`) +
  cell/role/conversation repos — cosine `<=>` search, soft-cap counts, FIFO `oldest`/`recent`.
- **Embedder port** (`memory/services/embedder.py`): injectable `Embedder` seam; `GatewayEmbedder`
  routes `role_key='embedder'` → YandexGPT **text-search-doc** (store) / **text-search-query**
  (search) — asymmetric, same 256-dim space; a failover to a chat-only provider raises
  `EmbeddingUnavailable` (503), never a wrong-dim vector. CI tests use a deterministic fake.
- **Services** (`memory/services/`): `CellMemoryService` / `RoleMemoryService` (embed-on-store,
  advisory soft caps 500/cell·200/role, distance→similarity recall, delete→404);
  `ConversationHistoryService` (FIFO window N=50 + summarize-on-overflow via an injected summarizer
  + cell-memory sink → `kind='conversation_summary'`).
- **API** (`memory/routers/memory.py`, `/api/v1/memory*`): cell list/search/add/delete +
  `/agents/{id}` role list/search/add/delete. Cell scope from the **RLS tenant context**
  (`get_current_cell_id`), not a client path param (RLS-authoritative, mirrors billing). Manual
  `POST` = the explicit «запомни». Soft-cap breach → `X-Memory-Soft-Cap-Exceeded` header (entry
  still stored). `MemoryError` → RFC-7807 handler. **Embedding vectors never serialized.**
- **Tenant dep** (`_shared/middleware/tenant_context.py`): new `get_current_workspace_id` (sibling
  of `get_current_cell_id`) for writers that persist `workspace_id`.

**Out of scope (named follow-up `01.4b — memory auto-extraction`):** the **LLM filter-agent**
(auto-after-task extraction) + the **LLM conversation summarizer** + their **orchestrator/worker
post-task wiring** + a `memory_curator` archetype seed + the live worker validation. Deferred
because the auto-trigger needs a NOT-NULL `agent_archetype_id` seed + an orchestrator hot-path
change + flaky-on-Windows live-worker validation — a focused-split per
`infra-pr-scope-prefers-focused-splits`. The **mechanism ships**: the summarizer is an injected
port (wired in 01.4b), and the **explicit «запомни» trigger is fully delivered** here.
Also deferred (ADR-011 later waves): RAG-inject into agent prompts (grill Q4), the
view/edit/delete **UI panel** (grill Q6 → `01.4-ui`), time-based retention sweep (90-day conv
history), >1yr auto-archive, PARA «Знания команды» (Wave 3).
