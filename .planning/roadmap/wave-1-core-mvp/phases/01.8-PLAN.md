## Key design choices (technical, pre-resolved by grill)

- TOTP secret at rest → `KMSProvider` (LocalAESKMS AES-256-GCM), `bytea` column.
- Two-phase enroll (pending → confirm) mirrors the account-recovery idiom.
- Backup codes: 10 × single-use, SHA-256 hashed — cheap + expected for 2FA.
- Login second factor = short-lived HS256 challenge token (no server state),
  type-guarded so it can't be confused with an access token.
- Magic-link built on the existing `EmailSender` port (InMemory in tests),
  consume = mark-used-then-issue (race-safe single-use).
- New iam tables are USER-scoped (no cell RLS) — matches the existing token
  tables; authz enforced by `user_id` predicates in the repos + `get_current_user`.
