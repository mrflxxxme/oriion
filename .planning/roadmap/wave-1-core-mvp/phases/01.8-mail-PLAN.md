## Risks / guards

- **Токен-утечка** — ключевой SECURE-инвариант: лог-строка = to+kind+host (без
  токена; caplog-тест подтверждает); sender ничего не персистит;
  `smtp_password` = SecretStr. Проверяется unit + SECURE-линзой.
- **Plaintext-auth по cleartext** — STARTTLS-путь ставит `start_tls=True`
  (aiosmtplib форсит TLS-апгрейд ДО AUTH); implicit-путь = SSL-on-connect.
  cert-verify нигде не отключён.
- **Credential-less prod crash** — `get_email_sender` детектит креды
  (`is_smtp_configured`) и падает на NoOp fallback; Settings-дефолты пустые/
  безопасные, app бутится. Selection-тесты покрывают все ветки.
- **Silently-swallowed send** — `aiosmtplib.send` raise пробрасывается (метод не
  ловит), задача падает. Unit `test_smtp_send_failure_propagates`.
- **Docker down** — не блокирует: транспорт замокан, нет DB-пути/миграций;
  unit-only локально. Нет `docker_integration` evidence-гейта.
- **CVE-drift нового dep** — `aiosmtplib 5.1.2` pip-audit 0 vulns, ships
  py.typed (mypy --strict без override).
- **Tripwire** — `src/iam/**` → `auth_rbac_sessions` → PR **не** auto-merge,
  требует founder ack. Отмечено в spec + PR body.
