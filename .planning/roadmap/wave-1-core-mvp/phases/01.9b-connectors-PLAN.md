## 1. Goal (verifiable)
Три собственных коннектора — **telegram-bot** (Bot-API scope), **yandex-disk**, **imap-smtp** — доступны агентам как native-tool callables (ADR-041), **read + draft only**; **каждый вызов** проходит DLP-скрин + capability-классификатор (fail-closed); creds — KMS-at-rest; autonomous SEND (send_email/send_telegram) = **deny-until-approval-UI (01.12)**; audit-строка на каждый внешний вызов. Готово = 3 коннектора отвечают через native-tool путь (mock-транспорт), DLP/capability-гейты доказаны на synthetic-входах, creds round-trip шифрованный, миграция pure-CREATE.

## 2. Scope
**In:** (1) connector clients под `backend/src/mcp/tools/connectors/` (telegram Bot-API read: getUpdates/channel posts + draft-message-as-artifact; yandex-disk read: list/download + draft; imap read: inbox fetch + draft-email-as-artifact) — паттерн `WebSearchTool`/`ReadURLTool` (rate-limited, typed `MCPError`, graceful-degrade). (2) NativeTool-closures + wiring в `runtime` (по образцу `web_search_runner`→`dispatch.build_leaf_runner`), gated. (3) **Capability-gate activation**: `requires_approval()` wired в leaf tool-dispatch; DANGEROUS send-tools denied; + **`agent_archetypes.tools_allowed` enforcement** (первый runtime call-site). (4) **`mcp.connector_credentials`** KMS-таблица (workspace-scoped RLS, mirror `byok_keys`) + `connector_credential_service` (store/get_plaintext/revoke via `get_kms_provider()`; fingerprint public-safe). (5) DLP-скрин на исходящих tool-call аргументах. (6) audit-строка per external call. (7) mock-транспорт unit + real-PG integration (creds RLS + round-trip).
**Out (адресовано):** **live connector smoke** (нужны founder-креды: TG bot-token, Yandex Disk OAuth, IMAP creds) → **DEFERRED-VERIFICATION DV-11** + запрос кредов отдельно (founder instruction 2026-07-09); Telegram Business-API → 01.11 (GATED RW-05); vertical-коннекторы (Bitrix/amoCRM/WB/Ozon) → Wave-2; **real MCP-protocol transport → Wave-2** (ADR-041).
