## Scope (delivered, 7 atomic commits C1–C7 + audit fixes)

- **Agents** (`agents/memory_curator.py`): `MemoryExtraction` (`should_remember` + `entries`, `kind ∈ {fact,note,glossary}`) via `PromptedOutput`; free-text summarizer agent; `MemoryCuratorDeps` + `MemoryCallBilling`; roles `memory_filter`/`memory_summary` → `deepseek-chat` in `ROLE_TO_MODEL` + `ROLE_TO_MAX_TOKENS`.
- **Archetype seed** (`agents/seed_data/memory_curator_v1.py`): idempotent horizontal `memory_curator` (`role_category='analyzer'`), wired into `TeamProvisioningService.provision_team` (not a team member — no agent_instance).
- **Runtime** (`runtime/memory_extraction.py`): `MemoryExtractor` (filter-agent → `CellMemoryService.add(source='filter_agent')` → bill), `build_memory_extraction_hook`, `LLMConversationSummarizer` (impl of the `ConversationSummarizer` port); `record_memory_call_step` in `runtime/dispatch.py` (mirror `record_master_call_step`; `step_type='llm_call'` — the CHECK has no `memory_extraction` value, so `phase` lives in `input_jsonb`).
- **Orchestrator seam** (`runtime/orchestrator.py`): `memory_extraction` hook (default `None ⇒ no-op`, mirrors `quota_admission`); runs on the SUCCESS path pre-final-write, folds cost into `ctx.accumulated_cost` + rolls memory tokens into `task.total_*_tokens`, **never rejects** (best-effort swallow); collision-free `step_index = len(leaf_outputs) + 2` (leaves 1..N, Master synthesis N+1).
- **Worker** (`runtime/queue/actor.py`): builds + forwards the real hook (`CellMemoryService` over a `GatewayEmbedder`), mirroring `quota_admission = enforce_quota_admission`.

**Billing invariant (critical):** the extractor writes the memory entries FIRST and
bills the `task_steps` row LAST, returning its cost only after the row exists; the
orchestrator folds that cost only on a clean return → `task.total_cost_credits ==
SUM(task_steps.cost_credits)` holds whether or not extraction runs, even under the
best-effort swallow.
