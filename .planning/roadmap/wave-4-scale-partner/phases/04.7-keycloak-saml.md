# Phase 04.7 — Keycloak параллельно с Logto (Enterprise SAML/AD/SSO)

- **Status:** Placeholder · Regenerate at Wave 4 start

## Overview

Enterprise-клиенты с SAML/AD/LDAP подключают свой IdP через Keycloak. Logto остаётся primary для self-serve СМБ-юзеров (миграция Custom JWT → Logto происходит в начале Wave 4).

Phase-spec регенерируется при старте Wave 4 на основе:
- Актуальных ADR — особенно [ADR-007](../../../decisions/ADR-007-authentik-then-keycloak.md)
- Wave 3 retro outcomes
- Customer demand на SAML/AD/SSO

## Scope highlights

- Keycloak deployment в k8s (high-available, отдельная Postgres)
- Federation strategy: Keycloak для Pro/Enterprise SAML, Logto для self-serve СМБ
- SAML 2.0 + OIDC поддержка
- AD/LDAP sync
- Per-tenant identity provider config
