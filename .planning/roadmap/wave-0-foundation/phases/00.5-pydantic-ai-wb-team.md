## Goal

Минимальный агентный runtime через Pydantic-AI. Первый team-preset (WB-Селлер) с 3 агентами: Coordinator + Listing Writer + Researcher. Пользователь ставит задачу Coordinator'у → он декомпозирует и делегирует → возвращает ответ + цитированные источники + draft-листинг через SSE stream.

**Acceptance metric:** task end-to-end latency p95 ≤ 90s для среднего workflow (~5 steps), SSE event delivery latency < 200ms p95, cost rollup accuracy 100% (parent.cost == sum(children.cost)).

### Delegation tool signature

```python
# backend/src/agents/tools/delegate.py
from pydantic import BaseModel, Field
from pydantic_ai import RunContext, Tool
from uuid import UUID

class DelegateInput(BaseModel):
    target_agent_id: UUID = Field(..., description="ID of team-member agent to delegate to")
    sub_prompt: str = Field(..., description="Task description for delegate (concise, actionable)")
    context_artifacts: list[UUID] = Field(default=[], description="Optional artifact references")

class DelegateResult(BaseModel):
    sub_task_id: UUID
    output: str
    cost_credits: Decimal
    tokens_used: int
    citations: list[Citation] = []
    artifacts: list[ArtifactRef] = []

async def delegate_task(ctx: RunContext[CoordinatorDeps], inp: DelegateInput) -> DelegateResult:
    """Delegate sub-task к team-member agent.

    Per ADR-016 (team-first UX) + ADR-024 (tasks contract):
      1. Validate target_agent_id ∈ ctx.deps.available_agents
      2. Validate delegation depth: count parent_task_id chain — if >5, raise DelegationDepthExceeded
      3. Create sub-Task row в tasks.tasks (parent_task_id = ctx.deps.task_id)
      4. Insert task_step (step_type='delegation', payload={target, sub_prompt})
      5. Execute target agent via orchestrator.execute_agent_task(sub_task_id) — awaits result
      6. Audit emit (delegation.created + delegation.completed)
      7. Cost rollup: child cost added to parent в tasks.task_steps; SSE event emitted
      8. Returns DelegateResult to coordinator
    """
```

### Task state machine (per tasks contract — inline reference)

```
pending ──> running ──┬──> completed
                      ├──> failed       (LLM 503, tool error, budget exceeded)
                      └──> cancelled    (user-initiated; cascades to children)

Invariants:
  - status transitions strict (no skip; running cannot return к pending)
  - parent.cost_credits = sum(children.cost_credits) after rollup phase
  - cancellation cascades children atomically (CASCADE via tasks.parent_task_id FK)
  - max parent chain depth = 5 (DelegationDepthExceeded raised otherwise)
```

```python
class TaskStreamEvent(BaseModel):
    """SSE payload — emitted to /api/cells/{id}/tasks/{tid}/stream subscribers.

    Per contracts/tasks/events.yaml event types — UI consumes для 00.7 frontend.
    """
    event_type: Literal[
        "task.started",
        "task.step_started",       # payload: { step_id, step_type: 'llm_call'|'tool_call'|'delegation', agent_id }
        "task.step_token",         # payload: { step_id, delta: <streaming token> }
        "task.step_completed",     # payload: { step_id, tokens, cost, duration_ms }
        "task.delegation_started", # payload: { sub_task_id, target_agent_id }
        "task.delegation_completed",
        "task.completed",          # payload: { result: CoordinatorOutput, total_cost_credits, total_duration_ms }
        "task.cancelled",
        "task.failed",             # payload: { error_type, retry_possible }
    ]
    task_id: UUID
    timestamp: datetime
    payload: dict
```

## Function signatures (key services)

```python
# backend/src/runtime/orchestrator.py
async def execute_agent_task(
    task_id: UUID,
    agent: Agent,                          # Pydantic-AI agent instance
    user_prompt: str,
    deps: BaseModel,
    sse_publisher: SSEPublisher,
    db: AsyncSession,
) -> CoordinatorOutput:
    """Drive Agent.run() with task-step persistence + SSE emission.

    Flow:
      1. Reserve budget (BudgetGuard check; raise BudgetExceeded if <50 T-credits)
      2. Emit SSE 'task.started'
      3. Persist task_step (type='llm_call', started_at) before each LLM call
      4. Stream agent.run_stream() — emit SSE 'task.step_token' per delta
      5. On tool_call (web_search, read_url, delegate_task) — persist task_step type='tool_call'/'delegation'
      6. On agent completion — persist final task_step (type='llm_call', tokens, cost, duration)
      7. Cost rollup: aggregate task_steps → task.cost_credits
      8. Emit SSE 'task.completed' with final CoordinatorOutput JSON
      9. Audit emit
      10. Refund unused budget (reserved - actual)
    """
    ...
```

### Integration test — full Coordinator→Researcher→Writer flow via TestModel

```python
# backend/tests/agents/test_coordinator_full_flow.py
import pytest
from pydantic_ai.models.test import TestModel
from src.agents.coordinator import coordinator_agent, CoordinatorDeps

@pytest.mark.integration
@pytest.mark.asyncio
async def test_coordinator_delegates_to_researcher_then_writer(
    db_session, sample_cell, sample_user, mock_sse_publisher
):
    """Integration: end-to-end WB-Селлер flow.

    Coordinator receives: 'Find top-3 competitors на WB по нише X, сделай draft-листинг'
      → delegates к Researcher (web_search + read_url) → returns market data
      → delegates к Listing Writer → returns draft markdown
      → Coordinator synthesizes CoordinatorOutput
      → SSE events emitted in expected order
      → cost rolled up: parent.cost == sum(children.cost)
      → result persisted в tasks.tasks
    """
    # Arrange: use Pydantic-AI TestModel (deterministic) instead of real LLM
    coordinator_agent.override(model=TestModel(call_tools=["delegate_task"]))

    deps = CoordinatorDeps(
        cell_id=sample_cell.id,
        task_id=uuid4(),
        user_id=sample_user.id,
        available_agents=[researcher_agent_instance, listing_writer_agent_instance],
    )

    # Act
    result = await coordinator_agent.run(
        user_prompt="Найди топ-3 конкурента на WB по нише X и сделай draft-листинг",
        deps=deps,
    )

    # Assert structured output
    assert isinstance(result.data, CoordinatorOutput)
    assert "competitors" in result.data.summary.lower() or "конкурент" in result.data.summary.lower()
    assert len(result.data.delegation_plan) >= 2     # at least Researcher + Writer
    assert len(result.data.citations) >= 1
    assert len(result.data.artifacts) >= 1            # draft-листинг artifact

    # Assert SSE events emitted в expected order
    emitted_events = [call.args[0].event_type для call in mock_sse_publisher.publish.call_args_list]
    assert "task.started" in emitted_events
    assert "task.delegation_started" in emitted_events
    assert "task.delegation_completed" in emitted_events
    assert "task.completed" in emitted_events

    # Assert cost rollup
    parent_task = await db_session.get(Task, deps.task_id)
    children = await db_session.execute(select(Task).where(Task.parent_task_id == deps.task_id))
    expected_cost = sum(c.cost_credits for c in children.scalars())
    assert parent_task.cost_credits == expected_cost
```
