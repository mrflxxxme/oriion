## Goal

PostgreSQL 16 + pgvector + RLS-политики per cell + bounded-context schemas + Alembic-миграции. Любой backend-запрос автоматически фильтруется по `cell_id` пользователя через RLS. **Acceptance metric:** RLS isolation 100% verified (cross-cell SELECT returns 0 rows), cell-provisioning < 30s.

### RLS context-setter helper (function signature)

```python
# backend/src/_shared/db/rls.py
from contextlib import asynccontextmanager
from uuid import UUID
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import text

@asynccontextmanager
async def set_tenant_context(session: AsyncSession, cell_id: UUID, user_id: UUID):
    """Set Postgres session-local config для RLS policy evaluation.

    Usage:
      async with set_tenant_context(session, cell_id=cell.id, user_id=user.id) as s:
          await s.execute(select(Task).where(...))   # RLS filters by cell_id automatically

    Postgres-level:
      SET LOCAL app.current_cell_id = '<uuid>';
      SET LOCAL app.current_user_id = '<uuid>';

    Used by FastAPI dependency get_tenant_db_session(user, cell_id).
    """
    await session.execute(text("SET LOCAL app.current_cell_id = :cell"), {"cell": str(cell_id)})
    await session.execute(text("SET LOCAL app.current_user_id = :user"), {"user": str(user_id)})
    try:
        yield session
    finally:
        # Postgres LOCAL settings auto-reset at transaction end
        pass
```

```sql
CREATE TABLE audit.audit_log (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    ts          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    actor_type  TEXT NOT NULL CHECK (actor_type IN ('user', 'agent', 'system')),
    actor_id    UUID,

    cell_id     UUID,

    payload     JSONB,
    ip          INET,
    user_agent  TEXT
) PARTITION BY RANGE (ts);

-- Initial partitions (rolling 12 months)
CREATE TABLE audit.audit_log_2026_05 PARTITION OF audit.audit_log
    FOR VALUES FROM ('2026-05-01') TO ('2026-06-01');
-- Auto-create future partitions via pg_partman OR cron (Wave 1+)

-- Append-only enforcement
CREATE OR REPLACE FUNCTION audit.deny_update_delete() RETURNS trigger AS $$
BEGIN
    RAISE EXCEPTION 'audit.audit_log is append-only';
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER audit_log_no_update BEFORE UPDATE ON audit.audit_log
    FOR EACH STATEMENT EXECUTE FUNCTION audit.deny_update_delete();
CREATE TRIGGER audit_log_no_delete BEFORE DELETE ON audit.audit_log
    FOR EACH STATEMENT EXECUTE FUNCTION audit.deny_update_delete();

-- Retention 3 years per FZ-152 — cleanup job Wave 3
```

### Per-cell schema provisioning function (multitenancy contract algorithm)

```sql
-- backend/alembic/versions/multitenancy/0002_cell_schema_template.sql
CREATE OR REPLACE FUNCTION multitenancy.provision_cell_schema(cell_uuid UUID)
RETURNS void AS $$
DECLARE
    schema_name TEXT := 'cell_' || replace(cell_uuid::text, '-', '_');
BEGIN
    EXECUTE format('CREATE SCHEMA IF NOT EXISTS %I', schema_name);
    EXECUTE format('GRANT USAGE ON SCHEMA %I TO oriion_app', schema_name);

    -- Per-cell tables (memory_entries with pgvector; tasks etc. per ADR-009)
    EXECUTE format($fmt$
        CREATE TABLE %I.memory_entries (
            id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
            content TEXT NOT NULL,
            embedding vector(1024),
            metadata JSONB DEFAULT '{}'::jsonb,
            created_at TIMESTAMPTZ DEFAULT NOW()
        )
    $fmt$, schema_name);

    EXECUTE format($fmt$
        CREATE INDEX %I_memory_embedding_hnsw ON %I.memory_entries
            USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64)
    $fmt$, schema_name, schema_name);

    -- (Per ADR-009, additional per-cell tables added by phases consuming them)
END;
$$ LANGUAGE plpgsql;
```

```python
# backend/tests/_shared/test_rls.py
import pytest
from uuid import uuid4
from src._shared.db.rls import set_tenant_context

@pytest.mark.asyncio
async def test_set_tenant_context_binds_session_local(db_session):
    """Unit: set_tenant_context applies SET LOCAL for both cell_id + user_id."""

    async with set_tenant_context(db_session, cell_id, user_id) as session:
```

### Integration test — RLS isolation per cell

```python
# backend/tests/multitenancy/test_rls_isolation.py
import pytest
from uuid import UUID
from src.multitenancy.services.cell_service import provision_cell, ProvisionCellCommand
from src.tasks.models import Task

@pytest.mark.integration
@pytest.mark.asyncio
async def test_rls_blocks_cross_cell_select(db_engine, sample_user_a, sample_user_b):
    """Integration: user в cell A не видит данные cell B даже с superuser-like query.

    Per ADR-009 + R-05 (data leak): RLS — основная защита. Тест на bypass обязателен.
    """
    # Arrange: provision 2 cells
    cell_a = await provision_cell(ProvisionCellCommand(
        workspace_id=sample_user_a.workspace_id,
        plan_tier="trial",
        requested_by=sample_user_a.id,
    ))
    cell_b = await provision_cell(ProvisionCellCommand(
        workspace_id=sample_user_b.workspace_id,
        plan_tier="trial",
        requested_by=sample_user_b.id,
    ))

    # Insert task into cell_a
    async with engine.begin() as conn:
        session = AsyncSession(bind=conn)
        async with set_tenant_context(session, cell_a.cell_id, sample_user_a.id):
            task_a = Task(cell_id=cell_a.cell_id, title="Cell A task")
            session.add(task_a)
            await session.commit()

    # Act: query tasks as cell_b user — should see 0 rows
    async with engine.begin() as conn:
        session = AsyncSession(bind=conn)
        async with set_tenant_context(session, cell_b.cell_id, sample_user_b.id):
            result = await session.execute(select(Task))
            visible_tasks = result.scalars().all()

    # Assert
    assert len(visible_tasks) == 0, "RLS leak detected — cell B sees cell A tasks"
```

- [ ] **AC1.** `alembic upgrade head` creates все 11 schemas + RLS policies + audit + cell-template function. Verified via `test_alembic_upgrade_idempotent`.

## Notes for AI-agents

- RLS context устанавливается через FastAPI dependency `get_tenant_db_session` — НЕ через global state
- Любая новая таблица с `cell_id` ТРЕБУЕТ RLS policy в той же миграции (AC6 enforces)
- Indexes на FK обязательны (Postgres не создаёт автоматически)
- Для cell-spawning: используем `multitenancy.provision_cell_schema(uuid)` функцию + apply template-migrations через Alembic programmatically (НЕ shell-level `CREATE SCHEMA` в коде сервиса)
- При encounter contract gap — escalate к architect, не правь contracts (per P-INIT-2)
- `pg_partman` setup deferred к Wave 1 — Wave 0 ограничивается sentinel-партицией + alert
