### Makefile (key targets)

```makefile
.PHONY: install dev test lint typecheck clean dev-bootstrap

install:
	cd backend && uv sync
	cd frontend && npm ci

dev:
	docker compose -f infra/docker-compose.dev.yml up -d
	@echo "→ Backend: http://localhost:8000 | Frontend: http://localhost:5173"

dev-bootstrap:
	@time ( $(MAKE) install && $(MAKE) dev && python scripts/wait_for_db.py && python scripts/seed_dev_data.py )
	@echo "✓ Bootstrap completed — verify via acceptance criteria"

test:
	cd backend && uv run pytest --cov=src --cov-report=term-missing --cov-fail-under=70
	cd frontend && npm test -- --coverage --run

lint:
	cd backend && uv run ruff check src tests
	cd frontend && npm run lint

typecheck:
	cd backend && uv run mypy --strict src
	cd frontend && npm run typecheck

clean:
	docker compose -f infra/docker-compose.dev.yml down -v
	rm -rf backend/.venv frontend/node_modules
```

## Acceptance Criteria (testable checks)

- [ ] **AC1.** `git clone && cp .env.example .env && make dev-bootstrap` — exits 0 with reported time ≤ 600s (10 min). Verified via Makefile `time` wrapper.
- [ ] **AC2.** `make test` passes on fresh clone (CI environment matches dev). Coverage ≥70% line + branch (enforced via `--cov-fail-under=70`).
- [ ] **AC3.** PR to `main` triggers all 4 CI workflows; each ≤ 8 min (`timeout-minutes: 8` enforced).
- [ ] **AC4.** Gitleaks job blocks test-PR с embedded AWS key (e.g. `AKIA[0-9A-Z]{16}` literal).
- [ ] **AC5.** License-scanner blocks test-PR с GPL-3.0 dependency added to `requirements.txt`.
- [ ] **AC6.** GitLab mirror sync schedule documented (`docs/gitlab-mirror.md`); execution Wave 1+.
- [ ] **AC7.** `compose down -v && compose up -d` — все healthchecks зелёные в течение 180s (integration test `test_compose_dev_starts_within_3_min` passes).
- [ ] **AC8.** `make lint` + `make typecheck` exit 0 on fresh skeleton (mypy --strict, ruff strict configs).
