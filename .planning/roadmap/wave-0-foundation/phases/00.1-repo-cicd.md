# Phase 00.1 — Repo & CI/CD

- **Owner:** DevOps · **Duration:** 3 дня · **Status:** Pending

## Goal

Monorepo с CI-pipeline, dev-окружением через `docker compose up`, pre-commit hooks. Любой новый разработчик / AI-агент стартует за <10 мин.

## Tasks

1. **Init monorepo** (`TEAMLY_RU/`)
   - [ ] `backend/` (Python 3.12 + FastAPI skeleton, `pyproject.toml` с ruff/mypy/pytest)
   - [ ] `frontend/` (Vite 6 + React 19 + TypeScript skeleton, `package.json`)
   - [ ] `infra/` (Docker Compose, Caddy config, Terraform stubs)
   - [ ] `docs/` (mkdocs.yml + базовая структура)
   - [ ] `.planning/` уже создан
   - [ ] `.claude/` + `AGENTS.md` для dev-агентов

2. **Pre-commit hooks** (`.pre-commit-config.yaml`)
   - [ ] ruff format + check
   - [ ] mypy --strict для backend
   - [ ] eslint + prettier (frontend)
   - [ ] gitleaks (secrets scan)
   - [ ] markdownlint

3. **GitHub Actions workflows** (`.github/workflows/`)
   - [ ] `ci-backend.yml`: ruff, mypy --strict, pytest+coverage, Semgrep, Bandit, pip-audit
   - [ ] `ci-frontend.yml`: eslint, tsc --strict, vitest, npm audit
   - [ ] `ci-security.yml`: gitleaks, trufflehog, Syft+Grype, Trivy на Docker-образах
   - [ ] `ci-license.yml`: forbid GPL/AGPL
   - [ ] Кэш зависимостей (uv для Python, pnpm для Node)

4. **GitLab mirror setup**
   - [ ] Self-hosted GitLab на отдельной VM в Yandex Cloud
   - [ ] Mirror sync каждые 4 часа из GitHub
   - [ ] `.gitlab-ci.yml` — passive failover копия GitHub Actions

5. **Docker Compose dev** (`infra/docker-compose.dev.yml`)
   - [ ] Postgres 16 + pgvector
   - [ ] Redis 7
   - [ ] Backend + Frontend services с hot-reload
   - [ ] Caddy reverse proxy

6. **Makefile/justfile** для команд: `dev`, `test`, `lint`, `migrate`, `clean`

7. **README.md** в корне: getting started за 10 мин

8. **CONTRIBUTING.md**: ссылка на `_meta/conventions.md`, `agent-handbook/00-START-HERE.md`

9. **Secrets handling**
   - [ ] `.env.example` с TBD-placeholder'ами из [PLACEHOLDERS.md](../../../PLACEHOLDERS.md)
   - [ ] `.env` в `.gitignore`
   - [ ] Lockbox-интеграция через Terraform (Yandex Cloud Lockbox)

10. **Yandex Tracker integration**
    - [ ] Webhook для creating issues из failed-PRs (Wave 1+)
    - [ ] Documentation в `docs/yandex-tracker.md`

## Acceptance Criteria

- [ ] `git clone && cp .env.example .env && docker compose -f infra/docker-compose.dev.yml up -d` → всё стартует за <3 мин
- [ ] `make test` проходит на чистом репо
- [ ] PR в `main` запускает все CI-gates, блокируется при fail
- [ ] gitleaks ловит подделочный AWS key в test-PR
- [ ] License-scanner блокирует test-PR с GPL-зависимостью
- [ ] GitLab mirror автоматически синхронизируется

## Risks

- **R-06** (AI ошибки): CI должен ловить supply-chain атаки → license + dep-scan обязательны
- **R-05** (utечки): .env никогда не коммитится, secrets через Lockbox

## Notes for AI-agents

- Backend в `backend/src/`, frontend в `frontend/src/`
- НЕ создавать `src/` в корне monorepo
- Bash-команды в Makefile должны работать на macOS + Linux + Windows (через `make` в WSL для Win)
- Cloud-провайдер: Yandex Cloud ru-central-1 (см. TBD_YC_FOLDER_ID_DEV в PLACEHOLDERS.md)
