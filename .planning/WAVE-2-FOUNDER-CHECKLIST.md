## Пошаговый план добычи

### 1. RW-04 — ЮKassa (запускать ПЕРВЫМ — самый длинный внешний процесс)
1. Решить **OQ-02**: ООО или ИП (влияет на комиссию, отчётность, лимиты). При сомнении — запросить у раннера разбор под конкретную ситуацию.
2. Заявка на yookassa.ru: реквизиты + расчётный счёт + описание сервиса («AI-ассистент для бизнеса, подписка»).
3. После одобрения (5–10 раб. дней) → создать **тестовый магазин** → `shopId` + тестовый секретный ключ.
4. `shopId` + секрет → `backend/.env` при старте 01.3b. Сказать раннеру «RW-04 ready» → фаза расфиксируется.
5. Параллельно (гейтит только live-flip, не тест): текст оферты с юристом.

### 2. RW-10 — pixel-художник (запускать на неделе 1; ~3 нед до готовых героев)
1. Тендер FL.ru / Хабр Карьера / Кворк: 3–5 кандидатов. Бриф: 2 героя (SMM-Анастасия, Крейтор-Денис), 64×64, 6 состояний (profile/idle/working/thinking/success/waving), РФ-стилистика, **work-for-hire (полная передача прав)**.
2. Выбор по style-fit → контракт ($400–1000/герой).
3. Приёмка — в фазе 02.7 (приёмный шов заложен). **Не гейтит волну** — если задержатся, скин живёт на 24 AI-архетипах.

### 3. RW-03 — Telegram bot-token (~5 мин; нужен к 02.3)
1. Telegram → @BotFather → `/newbot` → имя/username → токен.
2. Создать приватный тест-канал, добавить бота **администратором** (право публиковать), узнать `chat_id`.
3. Токен → `backend/.env` (`TELEGRAM_BOT_TOKEN`) + `TELEGRAM_TEST_CHANNEL_ID` рядом. Сказать «RW-03 ready».
> Даёт: live-доказательство approval-flow (02.3 — реальный пост в канал через подтверждение) + авторизацию Mini App (02.12).

### 4. RW-11 — image-gen ключ (~15 мин; нужен к 02.7)
1. Провайдер подбирается на discuss-шаге 02.7 по качеству пиксель-арта + лицензии (кандидаты: Recraft, Flux-хостинги и аналоги).
2. Завести аккаунт, пополнить ~$20–50, ключ → `backend/.env`. Сказать «RW-11 ready».

### 5. OAuth github/google (02.13) — заранее ничего не делать
Решается на discuss-шаге 02.13: обычно хватает тест-аккаунтов, которые заводит агент; если нужны твои — раннер даст точную инструкцию тогда.

### 6. DNS профики.online (02.8) — при деплое лендингов
Добавить A/CNAME корня на прод-бокс (5 мин; точные записи даст фаза). Корень = лендинги (Astro), `app.профики.online` = приложение.

### 7. RW-07 (опционально) — формальное закрытие Wave 0
Прогнать деплой-runbook + `demo_market_brief ... --runs 10` + `npm run e2e:live` против staging → артефакты в `.planning/gates/evidence/wave-0-to-1/` → подписать гейт (гасит DV-08/DV-09). На Wave 2 не влияет.
