# WB-Seller Domain Glossary

> Точная WB-терминология. Используется agent-prompts'ами + verified ссылками для anti-hallucination Level B.
> Source: Wildberries Help Center + Partner Portal (accessed 2026-05-13) + founder operating expertise.

## Идентификаторы товара

| Термин | Definition |
|--------|-----------|
| **Артикул WB** | Уникальный числовой идентификатор товара в системе Wildberries (присваивается автоматически при создании карточки). Используется в URL карточки и для API-запросов. |
| **Артикул продавца** | Внутренний код товара, который продавец задаёт сам (например, SKU из 1С). Помогает связывать WB-каталог с внутренним учётом. |
| **Баркод** | Штрих-код EAN-13 (или собственный), которым маркируется единица товара. Нужен для приёмки на склад WB. |
| **Базовый артикул** | Карточка-«родитель», объединяющая вариации (цвета/размеры) одного товара. Покупатель видит её как одну карточку с переключением вариантов. |
| **Вариация** | Конкретное цвето-размерное исполнение базового артикула. Имеет свой WB-артикул и баркод. |

## Карточка и контент

| Термин | Definition |
|--------|-----------|
| **Карточка товара** | Страница товара в WB (Title + photos + description + specs + reviews). Создаётся и редактируется через Partner Portal. |
| **Спецификации** | Структурированные характеристики товара (материал, размер, вес, цвет и т.д.), обязательные поля зависят от категории. Влияют на фильтры в поиске. |
| **Размерная сетка** | Таблица соответствия размеров (RU / INT / производитель) для категорий одежды и обуви. Влияет на процент выкупа. |
| **Объединение карточек** | Процесс объединения нескольких отдельных карточек одного товара в одну с вариациями (через WB Support). |
| **Категория** | Иерархическая классификация товара в каталоге WB. Определяет правила, требования к фото, обязательные характеристики и комиссию. |
| **Подкатегория** | Конечный уровень иерархии категорий, в который попадает товар (например, «Одежда → Женщинам → Платья → Вечерние»). |

## Логистика и склады

| Термин | Definition |
|--------|-----------|
| **FBO** (Fulfillment by Operator) | Хранение и отгрузка с WB-склада. Продавец поставляет товар оптом, WB обрабатывает заказы. |
| **FBS** (Fulfillment by Seller) | Хранение у продавца, отгрузка с WB-сортировки. Продавец сам собирает заказ и передаёт WB. |
| **DBS** (Delivery by Seller) | Продавец доставляет покупателю самостоятельно (например, своей курьерской службой). Используется редко, для крупногабарита. |
| **Сборочное задание** | Заказ покупателя, который продавец должен собрать и передать WB (для FBS/DBS). |
| **Транзитный склад** | Промежуточный сортировочный центр WB между складами и пунктами выдачи. |
| **Поставка на склад WB** | Операция отправки партии товара от продавца на WB-склад для модели FBO. |
| **Тариф логистики** | Стоимость доставки за единицу товара. Зависит от категории, объёма и плеча (склад → ПВЗ). |
| **Хранение** | Плата за нахождение товара на WB-складе. Растёт с временем простаивания. |

## Финансы и комиссии

| Термин | Definition |
|--------|-----------|
| **Комиссия WB** | % от продажи, который удерживает WB. Зависит от категории и модели (FBO vs FBS, обычно 12-23%). |
| **Эквайринг** | Сбор за обработку платежа (1.5-2% от суммы заказа). |
| **СПП** (Скидка Постоянного Покупателя) | Персональная скидка покупателя, частично компенсируемая WB, частично — продавцом (зависит от настроек). |
| **WB Wallet / Кошелёк WB** | Внутренний баланс покупателя, на который возвращаются деньги при возврате. Поощряет повторные покупки. |
| **Штраф за отсутствие** | Финансовая санкция за невозможность отгрузить заказ (нет товара) при модели FBS. |
| **Штраф за пересорт** | Санкция за отправку покупателю не того товара (по артикулу или вариации). |
| **Блокировка карточки** | Скрытие карточки из выдачи WB-модераторами (нарушение правил, контрафакт, жалобы). |

## Рейтинг и качество

| Термин | Definition |
|--------|-----------|
| **Рейтинг товара** | Средняя оценка карточки от 1 до 5 звёзд на основе отзывов покупателей. Ключевой фактор ранжирования. |
| **Рейтинг продавца** | Агрегированный показатель качества работы продавца (отгрузки, отмены, время ответа). Влияет на лимиты и привилегии. |
| **Отзывы** | Текстово-фото-видео обратная связь покупателя после получения товара. Видна всем посетителям карточки. |
| **Выкуп** | Покупка товара покупателем после ПВЗ-примерки (без возврата). Считается «выкупленным» заказом. |
| **Процент выкупа** | Доля заказов, завершившихся выкупом (а не возвратом). Норма ≥ 70%, низкий выкуп → ухудшение ранжирования. |
| **Возврат** | Отказ покупателя от товара после примерки. Возврат продавцу за его счёт. |

## Поиск и ранжирование

| Термин | Definition |
|--------|-----------|
| **Поиск WB** | Внутренний поисковый движок WB. Учитывает релевантность, рейтинг, конверсию, выкуп, остатки. |
| **CTR карточки** | Click-through rate — доля кликов по карточке относительно показов в выдаче. |
| **Конверсия в заказ** | Доля посетителей карточки, оформивших заказ. |
| **Конверсия в выкуп** | Доля заказов, завершившихся выкупом (см. выше). |

## Реклама и продвижение

| Термин | Definition |
|--------|-----------|
| **Реклама в карточке** | Платные показы карточек-конкурентов с подстановкой своей карточки в блок «рекомендуемые». |
| **Реклама в поиске** | Платная позиция в выдаче WB-поиска по выбранным ключевым словам. |
| **Авто-кампания** | Автоматическое размещение рекламы по релевантным позициям с фиксированным бюджетом. |
| **CPM / CPC** | Стоимость 1000 показов / 1 клика — модели тарификации WB-рекламы. |

## Акции и промо

| Термин | Definition |
|--------|-----------|
| **Акция (промо-кампания)** | Скидочная кампания WB с фиксированными условиями участия. Часть скидки — за счёт WB, часть — за счёт продавца. |
| **Глобальная акция** | Крупная распродажа по всему каталогу (11.11, Чёрная пятница, День рождения WB и т.д.). |
| **11.11** | Распродажа 11 ноября — одна из крупнейших акций года (≥ 50% всех годовых GMV отдельных продавцов). |
| **Чёрная пятница** | Распродажа конца ноября (даты варьируются год от года). |
| **День рождения WB** | Распродажа в честь основания компании (обычно январь). |
| **Бесплатный возврат** | Промо-инструмент: продавец компенсирует возврат, чтобы стимулировать заказы (используется для дорогих/нестандартных товаров). |
| **Доставка в течение часа** | Услуга экспресс-доставки в крупных городах (Москва, СПб). Требует FBO + остатков на ближайшем складе. |

## Инфраструктура продавца

| Термин | Definition |
|--------|-----------|
| **WB Personal Cabinet / Партнёрский портал** | Веб-интерфейс seller.wildberries.ru для управления каталогом, заказами, поставками, рекламой, финансами. |
| **WB Stat** | Раздел аналитики Partner Portal: продажи, остатки, воронки, экономика. |
| **API Wildberries** | openapi.wildberries.ru — REST API для интеграций (контент, заказы, реклама, аналитика). Требует токенов. |
