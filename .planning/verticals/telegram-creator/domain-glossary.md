## Канал и контент

| Термин | Definition |
|--------|-----------|
| **Канал** | Telegram-канал — публичная лента постов автора, читатели видят посты в подписках (не алгоритмическая лента). |
| **Рубрика** | Повторяющаяся тематическая категория постов (например, «экспертный понедельник», «кейс среды»), закреплённая за днём/ритмом публикации. |
| **Контент-план** | План публикаций на период (неделя/месяц): дата, тема, формат, рубрика. |
| **Пост** | Базовая единица контента — текст (+ опционально медиа). |
| **Сторис (Stories)** | Нативный формат Telegram для промо/тизер-контента, отдельный от постов ленты. |
| **Кружок (round video message)** | Короткое видео-сообщение для личного, «человеческого» контакта с аудиторией. |
| **Репёрпоузинг (repurposing)** | Адаптация одного исследования/инсайта под несколько форматов (пост → сторис → фоллоу-ап) без повторной работы с нуля. |
| **Форвард / репост** | Пересылка поста читателем в другой канал/чат — основной органический канал роста в Telegram (в отличие от алгоритмической рекомендации). |

## Аудитория и вовлечённость

| Термин | Definition |
|--------|-----------|
| **Охват (reach)** | Число уникальных пользователей, увидевших пост (обычно = число просмотров поста в статистике канала). |
| **ERR (Engagement Rate by Reach)** | `(реакции + репосты) / охват × 100%` — стандартная RU-метрика вовлечённости (TGStat/Telemetr). |
| **Отток подписчиков** | Доля отписавшихся за период — индикатор content-market fit проблемы, если растёт. |
| **Бенчмарк по размеру канала** | Референсный диапазон ERR/охвата для канала данного размера (например, 10-30% ERR — норма для <10K подписчиков, 5-15% — для 10K-100K). Абсолютное число ERR без учёта размера канала — недостаточно для вывода. |

## Монетизация

| Термин | Definition |
|--------|-----------|
| **Спонсорский пост (интеграция)** | Платное размещение рекламного поста рекламодателя в канале. |
| **Telegram Ad Platform / рекламная программа Telegram** | Официальная программа revenue-share Telegram — автор получает долю от нативной рекламы, показанной в канале. |
| **Telegram Stars** | Внутренняя валюта Telegram; используется для платных постов (pay-to-unlock) и платной подписки на канал. |
| **Платная подписка (paid subscription)** | Модель, при которой часть контента доступна только подписчикам, оплатившим доступ в Stars (ежемесячно/поквартально). |
| **Самозанятость / НПД** | Налог на профессиональный доход — типичный налоговый статус монетизирующегося автора (не юрлицо). Продукт даёт только операционные, не юридические/налоговые советы. |
| **Курс-автор** | Автор, монетизирующий канал через продажу собственного продукта (курс, консультации, сообщество) — вторая половина ICP вертикали «Telegram-крейтор / Курс-автор». |

## Регуляторика (РФ)

| Термин | Definition |
|--------|-----------|
| **ФЗ-38 «О рекламе»** | Федеральный закон, применяется к рекламе в Telegram так же, как к любой другой площадке — не делает исключений для мессенджеров. |
| **Маркировка рекламы** | Обязательная пометка «Реклама» + данные рекламодателя (наименование, ИНН) + erid-токен на любом платном/спонсорском посте. |
| **ОРД (Оператор рекламных данных)** | Сервис, выдающий erid-токены и передающий данные в ЕРИР. |
| **ЕРИР** | Единый реестр интернет-рекламы Роскомнадзора. |
| **erid** | Уникальный буквенно-цифровой идентификатор рекламного креатива, выдаваемый ОРД. |
| **Реестр блогеров РКН** | С 1 ноября 2024 г. — обязательная регистрация в Роскомнадзоре для каналов/страниц с 10 000+ подписчиков (Telegram — в списке платформ явно). Триггер: 10 дней с момента достижения порога. Незарегистрированный канал теряет право на рекламу/донаты и репосты от других. |

## Аналитика

| Термин | Definition |
|--------|-----------|
| **TGStat** | Ведущий RU-сервис аналитики Telegram-каналов (охваты, ERR, динамика подписчиков). |
| **Telemetr** | Альтернативный крупный RU-сервис аналитики + поиска каналов. |
| **Цитируемость (citation index)** | Показатель того, насколько часто на канал ссылаются/репостят другие каналы — прокси для авторитетности в нише. |
