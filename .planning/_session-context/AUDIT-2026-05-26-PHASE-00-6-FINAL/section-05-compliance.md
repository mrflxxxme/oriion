**Scope:** Phase 00.6 PR-B (branch `claude/gallant-lamport-f48eca`, commits `165b6ea`→`37bb934`), ahead of the Wave-0 anchor flip (`internal_demo_passed = true`, lands in final commit C9 after a pending founder 10× demo run). ### Verdict

**PASS WITH DEFERRED**

The ФЗ-152 control surface in `infra/terraform/` is enforced where it matters (region pinning is validated, no managed datastore is publicly exposed, RU-zone is the contract). The AC7 deferral is traceable end-to-end across three artifacts. The amended gate D5 does **not** drift from ADR-026 Level B — they govern different scopes (horizontal demo vs. vertical-template anti-hallucination), and the phase artifacts say so explicitly. The anchor-flip evidence **design** is audit-grade: reproducible CLI, per-run granular JSON, and a correct cohort p95 metric. No HIGH findings. The deferred items (Object Storage location pin not explicit; Loki/Tempo RU-residency retention is AC-W1-14; the actual evidence artifacts are a pending founder gate) are all governed and tracked. The anchor flip should proceed only once the evidence bundle physically lands in `.planning/gates/evidence/wave-0-to-1/` and `actual`/`passed`/`evidence_url` are populated in the gate frontmatter.

### Strengths

- **Region pinning is a hard fail, not a comment.** `variables.tf` `yc_zone` carries a `validation { condition = can(regex("^ru-central1-", var.yc_zone)) }` block — a non-RU zone fails `terraform plan`, not a runtime/manual check. This is a technical control over an administrative one (exactly the right posture for ФЗ-152).
- **No managed datastore is publicly reachable.** Managed PG sets `assign_public_ip = false` with an explicit ФЗ-152 + least-exposure comment; Managed Redis has no `assign_public_ip` (defaults false) and sets `tls_enabled = true` → `rediss://`. Both live intra-SG, reached only via the `self_security_group` predefined target.
- **Object Storage bucket is locked down for the audit-log ledger path.** `loki_archive` sets `anonymous_access_flags { read=false, list=false }` and a 90-day lifecycle that aligns to AC-W1-14. The audit-log 3-year retention requirement (ADR-009 §«Retention 3 года (ФЗ-152)») is correctly carried forward, not silently dropped.
- **Secrets are Lockbox-sourced, not committed.** `lockbox.tf` sources all LLM keys / JWT / BYOK master / Grafana admin from `sensitive` tfvars with empty defaults; `terraform.tfvars` is gitignored. The Grafana committed-password issue (F-SEC-M1) is closed via Lockbox injection.
- **AC7 deferral is traceable in three places, verbatim and consistent:** gate `internal_demo_passed.description` ("AC7 ... DEFERRED to Phase 01.1 retro post-Phase-00.7"), phase-spec `00.6-deploy-observability.md` §«Out-of-scope amendments» (line 44), and `01.1-retro.md` (the canonical lift target). No re-scoping drift between them.
- **ADR-018 V4 amendment is governance-complete:** status line updated (`amendment 2026-05-26`), V3/R1→V4 mapping table present, and the "no code impact" claim is accurate — the model name is a request parameter passed through `LLMRouter.route(...)` / `LLMGatewayModel`, not an enum; pricing-table refresh is correctly pinned to Wave-1 AC-W1-13.
- **Anchor-flip evidence design is reproducible and per-run granular.** `demo_market_brief.py` writes `run_{NNN}.json` per run + `summary.json`, matching the gate's required evidence shape. The cohort p95 is computed correctly (`statistics.quantiles(durations, n=20)[18]`, matching the gate's `n=20[18]` wording), and AC8 is evaluated as a cohort metric in `summary.json` (not a per-run flag), which is the corrected semantic from PR-B commit `72a61c9`.
- **Commit ledger is clean + atomic.** 8 PR-B commits (`C0`..`C8`), each scoped to one concern with a `[Phase 00.6 PR-B Commit N]` tag; the gate D5 + ADR-018 amendments are co-located in a single governance commit (`3b20a76`) with a commit body that documents the rationale and the deliberate decision to leave `target/actual/passed` untouched until C9.

### Dimension notes (no finding)

- **Gate D5 vs ADR-026 Level B — NO DRIFT.** ADR-026 Level B is the anti-hallucination gate for **vertical-templates** (golden-dataset ≥75% pass, adversarial probes 100%, source-citation frontmatter). Amended D5 gates the **horizontal `productivity-core` demo** (AC8 cohort p95 ≤120s, AC9 artifact shape, AC10 cost ≤30¢, ≥9/10 acceptance). The gate's own D4 notes state: "ADR-026 Level B applies to vertical-templates (W1+) — horizontal preset uses first-draft + replicate-failure-driven hardening pattern." The two contracts govern disjoint scopes by explicit design; the amended D5 does not weaken or contradict the ADR-026 Level B acceptance contract.
- **Loki/Tempo retention residency (ADR-009).** ADR-009 mandates 3-year audit-log retention in `ru-central-1` (ФЗ-152). Wave-0 keeps Loki at 7d on the VM disk (in-region by construction, since the VM is RU-zoned); the 90d retention + RU-bucket archival is correctly deferred to AC-W1-14 and the bucket target is pre-provisioned. Retention stays in-region throughout. No violation.
- **ADR-009 region lock** ("only `ru-central-1`", region-locked at provisioning) is consistent with the Terraform `yc_zone` regex and the `backend.tf` `region = "ru-central1"`. Coherent.
